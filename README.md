This repository includes:
1) Final Project Report
2) Final Project Presentation
3) Final Project Video (The file is too big to be uploaded on GitHub. Please visit https://www.youtube.com/watch?v=_WiOBmGDoj0)
4) RTOS (Real Time Operating System) Code in C for the Solar Panel Light Tracking System. This was created mainly by David Parker.
5) Folder with MATLAB files used for determining the proportional, derivative, and integral gain for the difference equation. This was created mainly by Alvin Nguyen.

Note: Some additional add-ons need to be installed for the MATLAB files. Some add-ons include Simulink Support Package for Arduino Hardware, Control System Toolbox, Simulink Control Design, and System Identification Toolbox. FreeRTOS and MPU6050 code need to be installed as well.
